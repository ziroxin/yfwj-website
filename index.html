常见问题

快速上手，新用户也能得心应手

1. 打开浏览器，搜索要追的剧集名称（例如：老友记），打开可播放视频的网页

2. APP自动识别页面中的视频资源

3. APP自动打开专属播放器，加载展示资源列表

4. APP自动开始播放视频，如果检测到新的资源，会实时更新资源列表

5. 可以观看在线视频，也可以点击下载按钮（支持自动提示下载），弹出下载对话框修改剧名，点击确定开始在下载

6. 在下载管理中查看进度，支持断点续传

边下边播：视频下载中就能开始看！已下载的部分自动播放本地资源，未下载的播放网络资源。

1. 开始下载一个视频

2. 在“下载中”列表内，点击“更多”按钮

3. 弹出菜单内点击“边下边播”

4. APP自动跳转专属播放器开始播放，已下载部分本地播放，未下载部分在线加载

5. 实时显示下载进度，下载完成自动切换本地资源！

1. 在专属播放器内播放视频时，点击右侧中间小窗播放按钮

2. 视频会缩小为可拖动的悬浮小窗（首次打开，会提示开启系统“在其他窗口上层显示”的权限）

3. 小窗可自由拖动调整大小，也可以随意拖动到屏幕任意位置

4. 支持通知栏控制：暂停/播放、上一集/下一集、长按倍速等

5. 点击右上角x号，或拖动到屏幕地区关闭区域，可快速关闭小窗（打开APP仍会继续播放）

1. 确保手机和投屏设备在同一局域网

2. 在播放界面点击投屏按钮

3. 系统会自动搜索可用的DLNA设备

4. 电视可以安装配套PC投屏软件，一键投屏，自动开始播放

5. PC端可以打开浏览器，手动输入投屏地址，直接播放

剧集选取：

1. 打开要追的剧集（例如：老友记第一季）列表页面

2. 点击APP底部导航“更多”按钮，点击“剧助手”，会进入选择剧集模式

3. 点选剧集所在区域（有辅助选择父级等），确定选取后，点击确认按钮

4. 自动解析区域内所有剧集，并弹出剧集选择弹窗（例如：第x集），输入剧集名称（老友记第一季）、选取要下载的剧集（支持全选），点击确定

解析下载：

5. 自动进入剧集解析页面，等待解析完成（关闭页面后，可以从左下角泡泡条重新打开）

6. 等待解析完成后，自动创建下载任务，下载成功的剧集，自动进入同一分组“老友记第一季”
